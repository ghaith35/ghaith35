## 🔬 Research

> **ModelShield** — *Detection and Neutralization of Malicious Weight Injections in Deep Learning Models*
>
> Master's thesis @ UBMA, supervised by Dr. Rachid Djerbi. The framework simulates weight-steganography attacks (adapted from MaleficNet), detects injected backdoors using a Siamese network with curriculum triplet mining, and neutralizes them via a denoising autoencoder — all without retraining the target model.

`PyTorch` `TensorFlow` `Siamese Networks` `Denoising Autoencoders` `Adversarial ML`
